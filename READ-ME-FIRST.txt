土豆兄弟·横版（Potato Brawl）—— 局域网联机 2D 横版动作游戏
================================================================

【最简单的开黑流程】

1. 双击 start.bat
   （依赖已经内置在压缩包里，离线也能跑；如果提示要装 Node.js，
    先到 https://nodejs.org/ 装一个 LTS 版，一路"下一步"即可）

2. 黑窗口里会打印两行地址：
       本机访问：   http://localhost:3000
       局域网访问： http://192.168.x.x:3000
   浏览器会自动打开本机地址。

3. 注册 / 登录：这个版本要先登录才能建房、进房。
   首页最上面填「账号 + 密码」-> 第一次点【注册】，之后点【登录】；
   刷新页面会自动保持登录。账号只用来记战绩和存档，密码是明文存在服务器
   data/accounts.json 里的（局域网自用才这么干，别把 data 目录共享出去）。

4. 建房的人：输入名字 -> 点【创建房间】
   其他人（同一个 Wi-Fi 下）：浏览器打开上面那个"局域网访问"地址，
   首页会自动列出房间，点一下就能进；也可以手动输入 4 位房间码。

5. 全员点【准备】-> 房主点【开始游戏】。

注意：关掉那个黑窗口 = 关闭服务器，别人就断线了，玩的时候别关。


【操作】

  移动         A / D   或  ← / →
  跳跃        空格 / W / ↑（可以二段跳）
  冲刺        Shift（冲刺瞬间有无敌帧）
  救人        站在倒地队友身边 3 秒
  升级三选一   1 / 2 / 3   或鼠标点卡片
  计分板       Tab
  属性面板     C
  聊天         Enter
  静音         M


【玩法】

  合作 PvE：最多 8 人一起守 20 波，每 5 波一个 Boss。
            武器自动开火，你只管走位；吃经验升级选道具，攒出自己的流派；
            波间用金币在商店买武器和道具；队友倒地了站过去 3 秒救起。

  PvP 死斗 / 团队战：场上会刷新武器箱和医疗包，击杀也能升级，
            先到分数上限（或时间到分数高）的一方获胜。

  无尽模式：没有波数上限，每 5 波一个 Boss、每 10 波额外送一次三选一，撑到全员倒地为止；
            最高波数和时长记在你账号上。

  存档点：每进一次商店，服务器自动写一个「波次检查点」。大厅右边的【存档点】面板里，
            房主点「从这里开始」就能接着存档的波次和 build 继续打，不用从第 1 波重来。


【备份 / 还原（明文 JSON，随便拷）】

  数据都在 potato-brawl/data/ 里，记事本就能打开看：
      accounts.json   账号（含密码）、战绩、无尽纪录
      saves.json      每局的波次检查点存档
      admin-key.txt   管理页口令（第一次启动自动生成，启动日志里也会打印）

  想要一份整包备份：
      浏览器打开 http://localhost:3000/admin 输入口令 -> 【导出备份】下载一个 JSON；
      或者命令行 npm run backup，文件在 backups/ 下。
  还原 / 换机器：
      管理页【导入】（可选「合并」；覆盖式还原前会自动留一份 backup-before-import-*.json），
      或者 npm run restore backups/xxx.json（服务器开着会拒绝，先关服务器）。
  手动改数据：服务器运行中改 data/*.json 会被内存里的版本盖掉，
      正确姿势是「导出 → 改文件 → 导入」，或者先停服再改。

【出问题了？先双击 troubleshoot.bat】

  它会自动检查：Node.js 版本、依赖是否装好、3000 端口是否被占用、
  本机局域网 IP 是多少，并给出对应的解决办法。

  端口被占用：命令行里执行  start.bat 8080  换一个端口。
  朋友打不开：1) 用"局域网访问"那个 192.168 开头的地址
              2) 第一次启动会弹 Windows 防火墙，必须点【允许访问】
              3) 有些公司/校园网开了"AP 隔离"，手机热点更省心
  要异地联机：这是局域网游戏，异地需要内网穿透（frp / ZeroTier / 花生壳）。


【目录说明】

  server/   服务端（权威模拟、房间、战斗逻辑）
  client/   网页客户端（原生 JS + Canvas，由服务器提供，朋友不用装任何东西）
  shared/   前后端共用代码（物理、关卡、武器、道具数值）
  test/     自动化测试与性能基准
  tools/    打包脚本
  README.md 完整架构设计、网络协议表、扩展建议

  开发者：npm install  &&  npm start
