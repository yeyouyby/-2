土豆兄弟·横版（Potato Brawl）—— 局域网联机 2D 横版动作游戏
================================================================

【最简单的开黑流程】

1. 双击 start.bat
   （依赖已经内置在压缩包里，离线也能跑；如果提示要装 Node.js，
    先到 https://nodejs.org/ 装一个 LTS 版，一路"下一步"即可）

2. 黑窗口里会打印两行地址：
       本机访问：   http://localhost:3000
       局域网访问： http://192.168.x.x:3000
   浏览器会自动打开本机地址。

3. 建房的人：输入名字 -> 点【创建房间】
   其他人（同一个 Wi-Fi 下）：浏览器打开上面那个"局域网访问"地址，
   首页会自动列出房间，点一下就能进；也可以手动输入 4 位房间码。

4. 全员点【准备】-> 房主点【开始游戏】。

注意：关掉那个黑窗口 = 关闭服务器，别人就断线了，玩的时候别关。


【操作】

  移动         A / D   或  ← / →
  跳跃        空格 / W / ↑（可以二段跳）
  冲刺        Shift（冲刺瞬间有无敌帧）
  救人        站在倒地队友身边 3 秒
  升级三选一   1 / 2 / 3   或鼠标点卡片
  计分板       Tab
  属性面板     C
  聊天         Enter
  静音         M


【玩法】

  合作 PvE：最多 8 人一起守 20 波，每 5 波一个 Boss。
            武器自动开火，你只管走位；吃经验升级选道具，攒出自己的流派；
            波间用金币在商店买武器和道具；队友倒地了站过去 3 秒救起。
            注意：地面怪现在会二段跳上平台追你（史莱姆/疯跑鸡/射手菌/石头人/炸弹怪/Boss 都会），
            站在台子上不再是绝对安全，只是把它们从「底下蹭墙」变成「排队上来挨打」。

  PvP 死斗 / 团队战：场上会刷新武器箱和医疗包，击杀也能升级，
            先到分数上限（或时间到分数高）的一方获胜。

  无尽模式：没有波数上限（每 5 波一个 Boss，每 10 波额外一次三选一），一直打到全员倒地；
            最高波数 / 时长 / 场次都记在你登录的账号上。

  存档点：每进一次商店自动写一个「波次检查点」；大厅右侧【存档点】面板里房主可以
            「从这里开始」，读的是存档里的波次、等级、武器、道具、金币，不回放战斗过程。
            战斗中点【保存进度】存的是「本波重打」：读档回到这一波开头，不会把打了一半的那波白送。


【账号、存档与备份】

  登录：这个版本必须先注册/登录才能建房和进房。用户名 2-20 位（中文/字母/数字/下划线），
        密码至少 4 位。刷新页面靠 localStorage 里的会话 token 免密重连；【退出登录】会清掉它。
        一个账号同时只有一个有效会话：在新机器登录后，旧机器的「免密登录」会失效（要重新输密码）。
        被顶下去的那台机器会当场收到提示，它在那局里的位置还在（不会把人踢出战斗），
        只是要重新登录才能再动账号和存档。
        连错 8 次密码会锁 60 秒。密码是明文存盘的（自订需求：整台机器可信、数据要能直接读改），
        要放到公网请务必改成 hash，见 server/src/data/accounts.js 顶部注释。

  数据文件：potato-brawl/data/
        accounts.json  账号 + 战绩 + 无尽纪录
        saves.json     波次检查点存档（默认最多留 200 条，超了丢最老的）
        admin-key.txt  管理页口令
        这三个都是明文 JSON，格式自己看得懂，也可以手改 —— 但要在服务器停着的时候改，
        跑着改会被内存里的版本盖掉。

  备份 / 还原：
        管理页   http://<服务器IP>:3000/admin  输入 admin-key.txt 里的口令
                 【导出备份】= 下载一份包含全部账号+存档的 JSON
                 【导入还原】= 覆盖或合并；覆盖前自动写 data/backup-before-import-*.json 好回滚
        命令行   npm run backup            → backups/potato-brawl-backup-<时间>.json
                 npm run data              → 列出账号与存档
                 npm run restore <文件>     → 还原（服务器在跑会拒绝，除非 --force）
                 node tools/data-cli.js verify <文件>   → 只查格式不动数据
        迁移机器 只要把导出的 JSON 在新机器 import 一次，账号和存档就全过去了。

  两条规则（第二轮代码审查改的）：
        删存档：只有存档归属人自己能删，房主也不例外 —— 否则谁拿到 id 就能把整间房看不到的存档清掉。
        读存档：房主可以拿别人名下的存档带全房一起接着打（共享进度，不等于共享账号）。
        别用同一个 data/ 目录开两个服务器：第二个会直接拒绝启动。要两份数据就 --data-dir <别的目录>，
        确实要硬开（自己承担互相覆盖的风险）才加 --force-data。
        盘满 / 目录被占用时，服务器关服会明确报错「数据没写干净」，不会假装已经保存好了。

  关登录（比如自己临时开一把懒得注册）：node server/index.js --no-login
  干脆不要账号/存档：node server/index.js --no-data

【出问题了？先双击 troubleshoot.bat】

  它会自动检查：Node.js 版本、依赖是否装好、3000 端口是否被占用、
  本机局域网 IP 是多少，并给出对应的解决办法。

  端口被占用：命令行里执行  start.bat 8080  换一个端口。
  朋友打不开：1) 用"局域网访问"那个 192.168 开头的地址
              2) 第一次启动会弹 Windows 防火墙，必须点【允许访问】
              3) 有些公司/校园网开了"AP 隔离"，手机热点更省心
  要异地联机：这是局域网游戏，异地需要内网穿透（frp / ZeroTier / 花生壳）。


【目录说明】

  server/   服务端（权威模拟、房间、战斗逻辑）
  client/   网页客户端（原生 JS + Canvas，由服务器提供，朋友不用装任何东西）
  shared/   前后端共用代码（物理、关卡、武器、道具数值）
  test/     自动化测试与性能基准
  tools/    打包脚本
  README.md 完整架构设计、网络协议表、扩展建议

  开发者：npm install  &&  npm start
